# 💻 FRIDAY Assistant (Windows Client)

Ваш персональный ИИ-помощник для ПК, наделенный зрением, слухом и возможностью физически управлять операционной системой. FRIDAY — это не просто чат-бот, это автономный агент на базе новейших моделей Google Gemini.

---

## 🌟 Ключевые технологии

### 🧠 Мультиагентная архитектура
В основе клиента лежат три независимых нейросети, которые общаются между собой:
1. **Фасад (Gemini Live 3.1):** Отвечает за мгновенное потоковое распознавание речи (STT), живой диалог, синтез голоса (TTS) и анализ видео с веб-камеры в реальном времени.
2. **Оркестратор (Gemini 3.5 Flash-Lite):** Быстрый мозг, принимающий решения. Строит планы, управляет процессами, программами и маршрутизирует задачи между устройствами в локальной сети.
3. **Тяжелый Мозг (Gemini 3.5 Flash Computer Use):** Визуальный VLM-агент. Анализирует скриншоты монитора с попиксельной точностью.

### 👁️ Нативное управление компьютером (Computer Use)
* **Автономные действия:** ИИ способен самостоятельно перехватывать контроль над мышью и клавиатурой для выполнения задач (поиск в браузере, клики по элементам интерфейса, набор текста).
* **Анализ экрана:** Чтение открытых вкладок, анализ интерфейсов программ, поиск элементов на экране рабочего стола.

### ⚙️ Глубокая системная интеграция
* Управление запущенными процессами (завершение задач).
* Поиск и запуск установленных программ.
* Управление системной громкостью, яркостью дисплея и медиаплеерами.

### 🎤 Голосовое взаимодействие
* Полностью потоковое общение без задержек.
* Возможность перебивать ассистента или добавлять контекст на лету.
* Поддержка дерзкого, живого стиля общения без жесткой цензуры.
